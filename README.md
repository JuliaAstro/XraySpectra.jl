# XraySpectra.jl

Utilities for loading and working with X-ray astronomical spectra and related response data.

> [!WARNING]
> This package is a work in progress and is under heavy development.

The package can read OGIP PHA spectra, RMF and RSP responses, ARF ancillary
responses, and background spectra. It also provides response folding and
explicit detector-channel rebinning.

See the [XraySpectra documentation](https://juliaastro.org/XraySpectra/dev/)
for installation, examples, and the API reference.
